★ 36,473

Solid 是一个用 TypeScript 编写的声明式 JavaScript 前端框架，专门用来构建用户界面。它最大的特点是采用细粒度响应式更新：通过代理追踪数据依赖，数据一变就只更新对应的那一小块 DOM，而不像 React 那样重新渲染整个组件。因此它性能很高、包体小，同时写法接近 React 的 JSX，上手容易。适合想兼顾开发体验和运行效率的 Web 项目，比如做数据看板或交互复杂的单页应用。
