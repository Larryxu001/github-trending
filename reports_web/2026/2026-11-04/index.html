floci-io/floci

★ 28,505

Floci 是一个用 Java 编写的本地 AWS 模拟器，让你在开发机上就能跑起 S3、SQS、EC2、ECS 等云服务，不用连真实 AWS 账号。它解决的是本地调试和自动化测试依赖云端、费钱又慢的问题。比如写上传文件的代码时，可以直接把请求指向 Floci 验证逻辑，配合 Testcontainers 还能在 CI 里跑集成测试，轻量免费。
